# פָּנִים 12 — יוגה לפנים

אפליקציית יוגה לפנים בעברית לנשים בנות 30–65: תוכנית של 12 שבועות, מדריכה בווידאו, קריינות עברית, מראה חיה ומאמנת פנים שרצה במכשיר.
בלי שרת, בלי חשבון, בלי טלמטריה. אותה ארכיטקטורה ואותה צנרת תוכן כמו [טאי צ'י 150](https://github.com/dudutal-dev/taichi).

האפיון המלא: "פנים 12 — אפיון אפליקציית יוגה לפנים" (8.11.2026), מבוסס על שני מסמכי המחקר של דודו.

## עקרונות

- **כנות מדעית.** כל תרגיל נושא תג ראיות (סעיף 7 בניתוח השיטה). אין "צעירה ב-5 שנים", אין "מוכח מדעית".
- **שחרור → הפעלה → הרמה**, מהצוואר למעלה. תרגילי כיווץ מגיעים עם ייצוב אצבעות, ועם התרעת קימוט במצלמה.
- **בטיחות קודם.** סינון בפתיחה (עפעף חדש ושיתוק פנים עוצרים), דילוג אוטומטי על אזורי בוטוקס ומילוי, וכפתור "כואב לי" (שני דיווחים מוציאים תרגיל).
- **פרטיות.** המצלמה מעובדת במכשיר בלבד (MediaPipe ב-WASM). התמונות נשמרות ב-IndexedDB ולא נכללות בגיבוי.

## מבנה

```
app/        PWA: Vite + React 19 + TypeScript + Tailwind 4 + Dexie + MediaPipe Tasks Vision
pipeline/   צנרת ElevenLabs (רצה פעם אחת, לא בזמן ריצה)
content/    התוצרים: manifest.json, video/, stills/, audio/, character/, mediapipe/face_landmarker.task
outputs/    תוצרי ביניים לבקרת איכות (לא נכנס לגיט, חוץ מגיליונות QA)
```

מקור אמת יחיד לתוכן: `app/src/content/exercises.ts`. האפליקציה מציגה ממנו, והצנרת מפיקה ממנו את תסריט הקריינות.

## הרצה

```
cd app && npm install && npm run dev      # http://localhost:5173
cd app && npm test                        # בדיקות יחידה
```

צנרת (Node 22; בסביבת הענן `NODE_USE_ENV_PROXY=1`):

```
node pipeline/00_check.mjs                       # בדיקת מפתח: TTS עברי + תמלול חזרה
node pipeline/build_script.mjs                   # תסריט מהספרייה + ניקוד
node pipeline/04_narration.mjs content/scripts/he/all.md   # רק שורות שהשתנו
node pipeline/keyframes.mjs <id...>              # תמונות מפתח
node pipeline/clips.mjs <id...>                  # קליפים + לולאה + גיליון QA
node pipeline/06_assemble.mjs                    # content/manifest.json
```

## איך מוסיפים קליף לתרגיל

1. תמונות מפתח ב-`pipeline/keyframes.mjs`: `<id>_pre` (ידיים במקום, פנים רגועות) ו-`<id>` (שיא). לתרגיל עיסוי מספיקה אחת.
2. קליף ב-`pipeline/clips.mjs`: `pingpong` (pre→שיא) או `loop` (אותה תמונה בהתחלה ובסוף).
3. QA: `outputs/stage2/<id>_sheet.jpg`. הכרעה ב-`pipeline/qa_status.json`. רק `approved` נכנס.
4. `node pipeline/06_assemble.mjs`.

כללי QA שנלמדו בפיילוט: לכתוב במפורש שהאצבעות לא עוזבות את העור כל הקליף; חיוך עם התנגדות יוצא טוב בניסיון ראשון.

## עלויות

נוצלו עד 8.11: **101,683 קרדיטים** מתוך 603,112 בחודש (מתחדש ב-8.12). זה מספר אמיתי מ-`/v1/user/subscription`.
הפירוט המשוער: 4 קליפי Veo בערך 19,400; קריינות ועיצוב קול בערך 15,000; 13 תמונות 2K בערך 67,000. מחיר התמונה (בערך 5,000 לתמונה) הוא הערכה בחיסור, כי ה-API לא מחזיר עלות.
אומדן לשאר הווידאו: 19 תרגילים, בערך 25 קליפים (כ-121,000) ועוד כ-38 תמונות מפתח (כ-190,000 ב-2K). בסך הכול כ-310,000.
אפשר לחסוך בתמונות מפתח ברזולוציה 1K. צריך לבדוק שזה לא פוגע בחדות הקליף.

## כללים קבועים

- האפליקציה לעולם לא קוראת ל-ElevenLabs.
- האפליקציה טוענת רק פריטים `approved` מהמניפסט. תרגיל בלי קליף מוצג כסטיל עם קריינות; שורה שלא הופקה נקראת בקול הדפדפן.
- כל קריאה לצנרת: retry, cache לפי hash, רישום עלות.
